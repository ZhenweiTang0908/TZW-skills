# Developer Self-Check

- [ ] The diff satisfies the approved behavioral contract.
- [ ] Scope is minimal and unrelated changes are absent.
- [ ] Naming, types, control flow, and responsibilities are clear.
- [ ] Errors are handled explicitly; exceptions are not swallowed.
- [ ] Side effects and external boundaries are visible.
- [ ] No speculative abstraction, debug output, dead code, or unexplained workaround remains.
- [ ] Tests observe behavior and important failure modes.
- [ ] Formatting, static checks, and relevant tests were run.
- [ ] Unverified behavior and residual risks are reported.
- [ ] No merge, deployment, migration, or production permission was assumed.
