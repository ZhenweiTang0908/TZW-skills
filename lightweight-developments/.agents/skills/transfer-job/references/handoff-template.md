# Handoff: <task name>

Only Objective, Done criteria, Plan, Verification, Constraints and Note are needed. Drop or add sections when the task requires it. Precision beats format: exact paths, exact commands, exact expected results.

## Objective

One sentence: what must be true when this is finished.

## Done criteria

- [ ] Observable, testable condition.
- [ ] Verification command and expected result.

## Plan

Ordered steps. Each step names its files and its check.

1. Step — files — check.
2. Step — files — check.

## Verification

Exact commands from the repo root, with expected output.

```bash
# install / test / typecheck / lint
```

## Constraints

- Working directory, branch, base commit.
- Files and directories not to touch.
- Dependencies allowed or forbidden; network access allowed.
- Destructive commands: forbidden unless listed here.
- Environment variable names only, never values.

## Note

Free space: uncertainties, warnings, links, edge cases, anything that does not fit above.
